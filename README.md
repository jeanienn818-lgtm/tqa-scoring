# TQA 看课打分台

按 V1.8 评分标准给 AI 课打分、记录问题；管理员看板汇总每日进度、双人一致性和问题导出。

- 网页：纯静态页面（`index.html` + `app.js`），由 GitHub Pages 发布。
- 数据与登录：Supabase（项目 `tqa-scoring`，新加坡区）。数据库结构与权限见 `supabase/schema.sql`。
- `config.js` 中的 anon key 是公开给浏览器用的，数据由数据库行级权限保护；不要把 service_role key 放进仓库。

## 角色
- **打分者**：管理员在「设置」里登记邮箱后，打分者首次打开网页选"首次使用 · 设置密码"，之后用邮箱和密码登录。只能看到、修改自己的记录。
- **管理员**：额外可以看看板、管理成员（添加、停用、重设密码、设置对比角色）、修改老师名单和目标范围。

## 修改网页
直接改仓库里的文件，推送到 `main` 分支后 1–2 分钟内生效。
